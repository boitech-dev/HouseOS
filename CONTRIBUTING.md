# Contributing

Themes, rooms, Nox tools and fixes are welcome: open a pull request, or show it in
[Discussions](https://github.com/boitech-dev/HouseOS/discussions).

- Start from the latest `master` and keep each change to one subject.
- How it is built and the rules a change follows: [AGENTS.md](AGENTS.md) ("Changing it safely").
- The checks to run before you open it: [docs/TESTING.md](docs/TESTING.md), including the privacy
  scan (no personal names, addresses or keys in the code or in commits).
- A security problem goes through [SECURITY.md](SECURITY.md), not a public issue.
