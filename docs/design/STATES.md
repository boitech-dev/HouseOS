# States matrix

Each room in each state people can meet, and where that state is shown in the Workbench (fixture
id) or tested. Filled in as each room moves to the design system (Part E); `—` = not yet,
`n/a` = cannot happen here (with the reason).

States: **first use** (nothing yet) · **loading** · **loaded** · **in progress** (something running) ·
**success** · **empty** · **error** · **offline** · **not configured** (a connection or device missing) ·
**no permission**.
